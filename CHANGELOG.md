# Changelog

All notable changes to the **PG-MambaGAN** project will be documented in this file.

## [v1.0.0] - 2026-05-08 (Clinical Grade Release)
### Added
- **Unit-Integral Shape Normalization** in `anatomy_nps.py`. NPS loss now directly optimizes the physical *shape* of the noise spectrum via `L1 Loss` rather than absolute magnitudes via `L2`.
- Documentation hierarchy in `docs/llm/` generated for LLM autonomy and advanced maintainer debugging.

### Changed
- **Xavier Normal Initialization**: Generator's final layer init changed from `Kaiming` (which caused Tanh saturation / white dots) and `Xavier Uniform` (which suppressed variance and killed gradients) to `Xavier Normal (gain=1.0)`.
- **EMA Decay Tuning**: Adjusted Exponential Moving Average decay from `0.999` to `0.99` to reduce visualization lag on Weights & Biases logging, eliminating "stale" evaluation metrics.
- Default VRAM configurations optimized for RTX 3080/4090/A100.

### Deprecated
- **Spectral Normalization**: Disabled `use_spectral_norm` in the Discriminator. Empirical data demonstrated a destructive interaction with WGAN-GP and NPS FFT losses, causing GP spikes (>3800) and Discriminator flatlines (~0.01).
- **Log1p Compression**: Removed `torch.log1p()` from the Noise Power Spectrum extraction as it unnecessarily crushed the spectrum's dynamic range.

---

## [v0.9.0] - 2026-04-18 (Stability Phase)
### Added
- **Fixed Sample Batches**: Implemented static sampling in `trainer.py` to allow 1:1 consistent visual monitoring of the same structural region across epochs.
- **Gradient Clipping**: Added `max_norm=1.0` to the Generator optimizer to protect against sudden infinite gradients generated by FFT-based losses.

### Fixed
- Addressed silent `gradient_checkpointing` freezing issues by manually overriding `requires_grad` during train/eval loops.
- Resolved Discriminator Spectral Norm buffer corruption by explicitly separating `D.eval()` during the Generator's adversarial update step.

---

## [v0.8.0] - 2026-04-01 (Metric Phase)
### Added
- **3D Volumetric Assembly**: Added `evaluation/volumetric.py` to stack 2D slice predictions into NIfTI (`.nii.gz`) format utilizing DICOM affine metadata (PixelSpacing, SliceThickness).
- **Clinical Constraints**: Integrated `get_body_mask()` to prevent 2D metrics (PSNR/SSIM) from artificially inflating by measuring background "air".
- **Hallucination Risk Analysis**: Added `pyradiomics` pipeline to extract and compare First Order and GLCM features from target tumor/tissue structures.
- **Dynamic Loss Scheduling**: Added Cosine Annealing scheduler. High L1 initially for structural alignment, cross-fading into high NPS later for texture generation.

---

## [v0.5.0] - 2026-03-15 (Initial Architecture Integration)
### Added
- Initial project structure ported from legacy TensorFlow 2.x to PyTorch 2.x and MONAI ecosystem.
- Integrated `mamba-ssm` (Selective State Spaces) into `vss_block.py` allowing 2D snake-scan (Z, Rev-Z, Col-Z) operations.
- First draft of the Anatomy-Aware Noise Power Spectrum (NPS) loss with automated NDCT-guided tissue segmentation (Fat, Soft Tissue, Lung).
- Added `preprocess.py` for DICOM to NPY conversion with rigorous `-1000` to `1000` Hounsfield Unit windowing and `[-1, 1]` normalization.
